# 📏 Metric Unit Conversion

A clean, responsive Metric Unit Conversion web application built with **HTML**, **CSS**, and **JavaScript**.

This project converts values between different measurement systems, including **Length**, **Volume**, and **Mass**, through a simple and intuitive interface inspired by digital measuring devices.
